# Bleach Calculator

This file [Bleach_concentration_calculator.py](https://github.com/molarxe/bleach-calculations/blob/main/Bleach_concentration_calculator.py) contations 5 variables that can be entered to get theoretical and realistic values for generationg bleach via direct-cell electrolysis.

## Variables :-

The variables one must change accordingly are :-

- MILLIAMPS
- BRINE_PERCENTAGE
- VOLUME_OF_WATER
- NUMBER_OF_CYCLES
- PERCENTAGE_OF_NAOCL_WANTED
